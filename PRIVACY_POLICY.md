PRIVACY POLICY

This application, Sensor Sync, was developed as part of an academic project.

I built this app to test sensor data collection, device communication, and basic server storage. While using the app, some data is processed and stored.

Data collected during usage:

Ambient light sensor values
Proximity sensor values
Device name and device UUID
Photos captured by the user

When I tested the app, each photo and sensor reading was stored locally on the device. The same data was also sent to a test server for display purposes.

The app does not collect personal identity information such as name, email, or location. No account is required to use the app.

The collected data is used only to:

Display readings inside the app
Sync data between connected devices
Show history on a local or test server

I did not integrate any third-party services. No analytics tools, ads, or external tracking systems are used.

All data remains within the app and the developer’s test environment. The app does not sell, share, or distribute user data.

This app is intended for learning and demonstration purposes only.
